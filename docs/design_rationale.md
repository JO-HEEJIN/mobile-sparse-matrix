## 문제 분석 (= 삽질 과정)

### 1. 처음 시도: 단순 2차원 리스트

```python
# 첫 번째 시도 (실패)
matrix = [[0.0 for _ in range(10000)] for _ in range(10000)]
# → 메모리 400MB 잡아먹음
# → "이거 말이 안 되네" 하고 포기
```

**실패 이유**: 
- 노트북 메모리가 부족해서 프로그램이 느려짐
- 100×100도 아니고 10000×10000이라니...

### 2. 두 번째 시도: 단순 딕셔너리

```python
# 두 번째 시도 (반쯤 성공)
matrix = {}  # {(row, col): value}
matrix[(0, 5)] = 1.5
matrix[(3, 7)] = 2.1

# 문제점 발견
for i in range(1000):
    for j in range(1000):
        if (i, j) in matrix:  # 이게 너무 느림
            print(matrix[(i, j)])
```

**문제점**:
- 행렬 곱셈할 때 한 행의 데이터 찾기가 너무 어려움
- (row, col) 튜플을 키로 쓰니까 메모리도 많이 먹음

### 3. 현재 방식: 이중 딕셔너리

```python
# 세 번째 시도 (현재)
matrix = {}  # {row: {col: value}}
matrix[0] = {5: 1.5, 7: 2.1}
matrix[3] = {2: 3.4}

# 장점 발견
row_data = matrix.get(0, {})  # 한 행 데이터 바로 가져오기 가능
```

**왜 이게 좋은가**:
- 행렬 곱셈할 때 한 행씩 처리하기 편함
- 메모리도 좀 덜 먹는 것 같음 (정확히는 모르겠지만)

```python
        # 저장 안 함
```

**결정 과정**:
1. 처음에는 정확히 0.0만 제외
2. 테스트하다 보니 부동소수점 오차로 0.0000000001 같은 값들이 저장됨
3. 구글링해보니 1e-12가 적당하다는 글을 봄
4. 그냥 1e-12로 결정

### 2. 메모리 사용량을 어떻게 계산할까?

```python
def memory_usage(self) -> int:
    # 진짜 메모리 사용량은 모르겠고...
    # 대충 추정해보자
    
    dict_overhead = len(self._data) * 64  # 딕셔너리 하나당 64바이트? (추정)
    value_storage = self._nnz_count * 24  # int+int+float = 24바이트? (추정)

```

**솔직한 고백**:
- Python 메모리 사용량 정확히 계산하는 방법을 모르겠음
- 대충 인터넷에서 찾은 수치들로 추정
- 실제로는 더 복잡할 것 같은데...

### 3. 언제 가비지 컬렉션을 할까?

```python
# 고민: 언제 청소를 해야 할까?
```

- 너무 자주 하면 느려질 것 같고

## 행렬 곱셈 알고리즘 (= 가장 많이 삽질한 부분)

### 1. 첫 번째 구현 (순진한 방법)

```python
def multiply_naive(A, B):
    C = MobileSparseMatrix(A.rows, B.cols)
    
    # 3중 루프 - 너무 느림
    for i in range(A.rows):
        for j in range(B.cols):
            for k in range(A.cols):
                a_val = A.get(i, k)
                b_val = B.get(k, j)
                if a_val != 0 and b_val != 0:
                    current = C.get(i, j)
                    C.set(i, j, current + a_val * b_val)
```

- 500×500 행렬 곱셈에 30초 걸림
- "이건 쓸 수 없다" 판단

**개선 결과**:
- 500×500 행렬 곱셈이 2초로 단축
- "오, 이제 좀 쓸 만하네" 느낌

### 3. 최적화 버전 (나중에 추가)

```python
def multiply_optimized(A, B):
    # 더 빠르게 만들어보자
    # 사전에 어떤 행/열이 비어있는지 체크
    active_rows_A = set(A._data.keys())
    active_rows_B = set(B._data.keys())
    
    # 교집합만 계산 (쓸모없는 계산 제거)
    useful_dims = active_rows_A & set(range(A.cols)) & active_rows_B
```

**최적화 효과**:
- 또 1초 정도 단축됨
- 하지만 코드가 복잡해짐 (트레이드오프)

```python
    if row in self._data and col in self._data[row]:
```
