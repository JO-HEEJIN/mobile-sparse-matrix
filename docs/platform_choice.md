## 왜 소셜 네트워크를 예시로 했는가

### 1. 희소행렬 쓰기 좋은 예시

```python
# 생각해보니 친구 관계가 딱 희소행렬임
users = 10000  # 만 명 사용자
average_friends = 150  # 평균 친구 150명
density = 150 / 10000  # 1.5% 밀도
# → 98.5%가 0인 전형적인 희소행렬!
```

### 2. 직관적으로 이해하기 쉬움

"친구의 친구 추천"이라고 하면:
- 면접관도 바로 이해할 수 있음
- 실제로 쓰는 기능이라서 현실적
- 행렬 곱셈의 의미가 명확함

### 3. 확장성 보여주기 좋음
