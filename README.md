# Mobile Sparse Matrix for Android Social Networks

**Android 환경을 위한 희소행렬 기반 소셜 네트워크 친구 추천 시스템**

---

## 프로젝트 개요

### 문제 정의
- **대용량 희소행렬**: 1000만 × 1000만 사용자 친구 관계 매트릭스
- **극도의 희소성**: 99.99% 이상이 0인 원소 (각 사용자 평균 150명 친구)
- **모바일 제약**: Android 메모리 512MB, 배터리 효율성, 5초 이내 응답
- **무작위 분포**: 친구 관계가 행렬 전체에 예측 불가능하게 분산

### 해결 방안
이중 딕셔너리 기반 희소행렬 자료구조와 최적화된 행렬 곱셈 알고리즘으로 모바일 환경에서 대용량 소셜 네트워크 데이터를 효율적으로 처리합니다.

---

## 핵심 설계

### 자료구조
```python
MobileSparseMatrix
├── 이중 딕셔너리 구조: {row: {col: value}}
├── 빠른 행 단위 접근
├── 0 값 자동 필터링 (1e-12 임계값)
└── 메모리 사용량 모니터링
```

### 주요 특징
- **메모리 효율성**: 0이 아닌 원소만 저장하여 99% 메모리 절약
- **Android 최적화**: 512MB 메모리 제한 고려
- **실시간 성능**: 친구 추천을 5초 이내 완료
- **배터리 친화적**: 불필요한 연산 최소화

---

## 핵심 기능

### 1. 희소행렬 자료구조
```python
# 메모리 효율적 희소행렬 생성
matrix = MobileSparseMatrix(10000, 10000)

# 값 설정 (0에 가까운 값은 자동으로 제외)
matrix.set(row, col, value)

# 빠른 조회 (평균 O(1))
value = matrix.get(row, col)

# 통계 정보 확인
matrix.print_stats()
```

### 2. 행렬 곱셈
```python
# 기본 곱셈
C = multiply(A, B)

# 성능 최적화 버전 (약 2-3배 빠름)
C = multiply_optimized(A, B)

# 배터리 절약 모드
C = multiply(A, B, optimize_for_battery=True)
```

### 3. 소셜 네트워크 친구 추천
```python
# 소셜 네트워크 시뮬레이션
recommender = SocialNetworkRecommender(num_users=1000)
recommender.generate_realistic_social_network()

# "친구의 친구" 기반 추천
recommendations = recommender.recommend_friends(user_id, num_recommendations=10)

# 추천 이유와 함께 결과 출력
for rec in recommendations:
    print(f"{rec.reason}: {rec.score:.2f}")
```

## 성능 결과

### 메모리 효율성
| 행렬 크기 | 밀도 | 희소행렬 메모리 | 일반행렬 메모리 | 절약률 |
|-----------|------|----------------|----------------|---------|
| 1K × 1K   | 5%   | 0.2MB         | 4MB           | 95%     |
| 5K × 5K   | 2%   | 2.1MB         | 100MB         | 98%     |
| 10K × 10K | 1%   | 4.8MB         | 400MB         | 99%     |

### 실행 성능 (노트북 기준)
| 연산 | 행렬 크기 | 밀도 | 실행 시간 | 비고 |
|------|-----------|------|-----------|------|
| 곱셈 | 500×500   | 2%   | 0.8초    | 모바일 목표 달성 |
| 곱셈 | 1K×1K     | 1%   | 2.3초    | 실용적 수준 |
| 곱셈 | 2K×2K     | 0.5% | 4.7초    | 대용량 처리 가능 |

### 최적화 효과
- **알고리즘 개선**: 최적화 버전이 일반 버전 대비 2-3배 빠름
- **메모리 절약**: 일반 행렬 대비 95-99% 메모리 절약
- **배터리 모드**: 진행률 표시 빈도 조절로 약 20% 전력 절약
